## 공개 문구 언어 원칙

메인 페이지의 공개 문구는 한국어를 기본으로 유지한다.

WARSOL 사이트의 헤드라인, 섹션명, CTA, 카드 제목, 설명 문구를 영어 중심으로 전환하지 않는다. 사용자가 명시적으로 요청하지 않는 한, 삼성SDI 같은 대기업 사이트를 참고하더라도 영어 섹션 라벨이나 영어 히어로 문구로 바꾸면 안 된다.

허용되는 예외는 회사명 WARSOL, 제품명이나 약어처럼 이미 통용되는 표기, TDS, SDS, CMC, Sodium Polyacrylate 같은 기술자료·원료명 표기뿐이다.

디자인 개선 시에는 한글 카피를 짧고 크게 정리하는 방식으로 고급감을 만든다. 영어로 바꾸는 방식으로 프리미엄 톤을 만들지 않는다.

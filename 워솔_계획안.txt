좋습니다. 이건 그냥 “회사 홈페이지”가 아니라 **워솔의 기술력·특허·소재 R&D 이미지를 대기업급으로 보이게 하는 B2B 프리미엄 케미컬 테크 웹사이트**로 잡겠습니다. 방향은 **React 기반 최신 웹 + 고급 인터랙션 + 실제 공개자료 기반 콘텐츠 + 반응형/SEO/문의 전환까지 완성**입니다.

## 0. 먼저 잡은 핵심 포지셔닝

공개자료 기준으로 대상은 **주식회사 워솔 / WARSOL.,Inc**, 대표자는 **이창주**이며, 제조업·화학제품 제조업 계열로 분류되고 주요제품은 **수용성고분자**, 종목은 **접착제 및 젤라틴 제조업**으로 기재되어 있습니다. 공개 DB에는 홈페이지, 전화, 팩스, 주소, 사업자번호, 등록일 등의 정보도 함께 올라와 있습니다. ([Bizno][1])

또 다른 공개 기업정보에서는 워솔을 **아크릴·우레탄·비닐 수지를 기반으로 한 점착제, 접착제, 기능성 코팅제, 분산제 등을 개발·생산하는 기술 집약형 화학 소재 기업**으로 설명하고 있고, 2005년 설립, 대표자 이창주, 산업용 특수 수지 및 점·접착제 제조 사업을 핵심 영역으로 제시합니다. 다만 이 자료는 “각종 데이터를 기반으로 한 요약”이며 2025년 11월 기준 업데이트 자료라고 밝히므로, 최종 홈페이지 반영 전에는 사업자등록증·회사 소개서·공식 로고 파일로 한 번 더 확정하는 게 좋습니다. ([RnDcircle][2])

특허·기술 스토리도 충분히 만들 수 있습니다. 예를 들어 워솔은 **커피찌꺼기를 이용한 친환경 자연발화억제제 및 사용방법** 특허의 원출원인으로 표시되어 있고, 해당 특허는 2024년 1월 16일 공개·등록 흐름과 함께 친환경 자연발화억제제, 커피찌꺼기 재활용, 석탄 자연발화 억제 효과를 설명합니다. ([구글 특허][3]) 또한 **고기능성 차열도료 조성물 및 차열방수 시공방법** 특허에는 주식회사 워솔이 특허권자로 함께 기재되어 있으며, 차열·단열·방수·내후성 관련 기술 설명이 포함되어 있습니다.  과거 특허 중에는 **내수성 및 방수성이 개선된 수성 아크릴계 에멀젼 방수성점착제**도 있어, 제품/기술 페이지의 신뢰 요소로 좋습니다. 

로고는 이미지 검색에서 과거 **WARSOL Inc. 회사소개 자료 표지로 보이는 이미지와 주식회사 워솔 심볼**이 확인되지만, 실제 웹사이트에는 반드시 공식 로고 원본 파일, 회사 소개서, 명함/간판/브로슈어 기준으로 확정해서 넣는 방식으로 가겠습니다.

## 2. 기술 스택

대기업급 사이트로 만들려면 단순 React SPA보다 **SEO, 성능, 라우팅, 이미지 최적화, 메타데이터 관리**가 좋은 구조가 필요합니다.

| 영역        | 선택                                                  |
| --------- | --------------------------------------------------- |
| 프레임워크     | **Next.js + React**                                 |
| UI        | React 컴포넌트 기반                                       |
| 언어        | TypeScript                                          |
| 스타일       | Tailwind CSS + CSS Modules 일부                       |
| 애니메이션     | Framer Motion / GSAP / CSS scroll animation         |
| 3D/고급 비주얼 | Three.js 또는 React Three Fiber                       |
| 콘텐츠 관리    | `content/warsol.ts` 또는 MDX 기반                       |
| 문의        | Form API / Email 연동 준비                              |
| 배포        | Vercel 또는 정적/서버 배포 모두 가능                            |
| 검증        | ESLint, TypeScript check, build, Lighthouse, 반응형 QA |

현재 React 공식 문서는 최신 버전을 **19.2**로 안내하고 있고, Next.js 공식 문서는 최신 버전을 **16.2.6**으로 표시합니다. ([React][4]) 특히 2026년 5월 Next.js 보안 릴리스에서는 React/Next.js 패치 버전으로 업그레이드하라고 권고하므로, 구현 시 보안 패치가 반영된 최신 안정 버전을 쓰는 쪽이 맞습니다. ([Vercel][5]) Tailwind CSS는 현재 v4.3으로 표시되며 유틸리티 기반으로 빠르게 현대적인 웹 UI를 구성할 수 있고, 반응형 디자인에도 적합합니다. ([tailwindcss.com][6]) Vite는 별도 React 단독 앱이나 컴포넌트 실험 환경이 필요할 때 후보로 둘 수 있지만, 대표 웹사이트 본체는 Next.js가 더 적합합니다. ([vitejs][7])

## 8. 제품 페이지 구성

제품 소개는 “예쁜 카드”보다 **B2B 구매자가 신뢰할 수 있는 정보 구조**가 중요합니다.

각 제품 상세 구성:

* 제품명
* 한 줄 정의
* 적용 산업
* 주요 특징
* 기술 기반
* 기대 효과
* 문의 CTA
* 관련 특허/기술 연결

예시:

**내수성 개선 수성 아크릴 에멀젼 점착제**

* 적용: 건축 방수시트, 산업용 라벨, 습도 노출 환경
* 특징: 내수성, 방수성, 접착 유지력
* 연결: 수성 아크릴계 에멀젼 방수성점착제 특허 스토리

**고기능성 차열도료 / 차열방수 솔루션**

* 적용: 건축 외피, 지붕, 방수 시공
* 특징: 차열, 단열, 방수, 내후성
* 연결: 고기능성 차열도료 조성물 특허

**친환경 자연발화억제제**

* 적용: 석탄 저장, 에너지/발전 산업, 야적장 안전
* 특징: 커피찌꺼기 활용, 피막 형성, 자연발화 억제
* 연결: 커피찌꺼기 기반 친환경 자연발화억제제 특허

## 9. “간지” 구현 포인트

여기서 사이트 퀄리티가 갈립니다.

1. **첫 화면을 영화 오프닝처럼 만든다**
   어두운 배경, 고급 타이포, 느린 3D 움직임, 짧고 강한 문장.

2. **제품을 화학소재 플랫폼처럼 보여준다**
   “제품 리스트”가 아니라 “기술 플랫폼 → 산업 적용 → 제품군” 흐름.

3. **특허를 브랜드 스토리로 바꾼다**
   특허 번호만 나열하지 말고, “왜 이 기술이 필요한가 → 어떤 문제를 해결하는가”로 설명.

4. **사진이 없으면 싸구려 스톡을 피한다**
   실제 공장/연구소/제품 사진을 우선하고, 부족하면 추상 3D 소재 비주얼로 고급스럽게 처리.

5. **모바일에서도 고급스럽게**
   데스크톱만 예쁘고 모바일에서 깨지면 바로 중소업체 템플릿 느낌이 납니다. 모바일에서는 애니메이션을 줄이고 타이포/간격/CTA를 살립니다.

## 11. 작업 순서

### Phase 1 — 자료 수집/정리

워솔 공개자료, 로고 후보, 특허, 제품군, 회사정보, 연혁을 수집해서 `content` 데이터로 정리합니다. 이때 워솔KJT 등 비슷한 이름의 회사 정보가 섞이지 않게 분리합니다.

### Phase 2 — 정보구조/카피 작성

Home, Company, Technology, Products, R&D, Contact의 카피를 워솔 전용으로 작성합니다. AI 티 나는 문구는 빼고, 화학소재 B2B 기업 톤으로 갑니다.

### Phase 3 — 디자인 시스템 구축

컬러, 폰트, 레이아웃, 버튼, 섹션, 카드, 타임라인, CTA를 먼저 만듭니다.

### Phase 4 — React/Next 구현

Next.js + React + TypeScript + Tailwind 기반으로 페이지를 구현합니다. Hero에는 고급 인터랙션을 넣고, 제품/특허/문의 영역은 데이터 기반 컴포넌트로 만듭니다.

### Phase 5 — 반응형/SEO/QA

모바일 화면, 빌드, Lighthouse, 메타태그, sitemap, 문의 폼, 지도/연락처, OG 이미지까지 검증합니다.
